### 1.1 一个程序由哪几部分组成

C 程序的最小完整形态包含三样东西：预处理指令、函数和语句。预处理指令以 # 开头，在编译前由预处理器处理，最常见的是 #include <stdio.h>，它把标准输入输出的函数声明引入当前文件。函数是 C 程序的基本单位，任何一个可运行的程序都必须有且只有一个 main 函数，程序从 main 的第一条语句开始执行。语句以分号结束，用花括号组成语句块。

>[!note]c语言结构基础
>这是一个标准的c语言入门程序

```c
```
```c
#include <stdio.h> /* 预处理指令：引入标准输入输出 */

int main(void) /* 主函数，程序入口 */

{

	printf("Hello, C!\n"); /* 函数调用语句 */

	return 0; /* 向操作系统返回 0，表示正常结束 */

}
```

这段代码里每个部分都有明确职责：#include 决定能用哪些库函数；int main(void) 中的 int 表示返回给系统的整数，void 表示不接收命令行参数；printf 是标准库函数，\n 是转义字符，表示换行；return 0 是函数返回值，与 int 对应。初学者常见的“编译成功但运行闪退”，往往就是漏了最后这一句或返回值类型不匹配。
