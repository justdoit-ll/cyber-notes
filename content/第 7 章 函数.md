从函数的形式看，函数分为两类。 
① **无参函数**。如 print_star 和 print_message 就是无参函数。在调用无参函数时，主调函数不向被调用函数传递数据。无参函数一般用来执行指定的一组操作。例如，例 7.1 程序中的 print_star 函数的作用是输出 18 个星号。无参函数可以带回或不带回函数数值，但一般以不带回函数值的居多。注意，在 C23 标准中，`void print_star()` 意味着 print_star () 函数不接受任何参数，而在 C17 及以前的 C 语言标准中，意味着 print_star () 函数可以接受任何参数包括没有参数。所以建议在使用尚未支持 C23 的 C 语言编译器的时候写成 `void print_star(void)`，`void print_message(void)`，`int main(void)`。

② **有参函数**。在调用函数时，主调函数在调用被调用函数时，通过参数向被调用函数传递数据，一般情况下，执行被调用函数时会得到一个函数值，供主调函数使用。例 1.3 的 max 函数就是有参函数，从主函数把 a 和 b 的值传递给 max 函数中的参数 x 和 y，经过 max 的运算，将变量 z 的值带回主函数。此时有参函数应定义为与返回值相同的类型（例 1.3 的 max 函数定义为 int 型）


## 一、函数定义

就是**告诉编译器这个函数叫什么、要什么参数、返回什么类型、里面做什么**，相当于写好这个功能的代码。 格式：

```
返回值类型 函数名(参数列表)
{
    函数体;
}
```

- 无参：`void f(void)`，没有参数接收数据
- 有参：`int max(int x, int y)`，定义要接收的参数
- 作用：封装一段独立功能（求阶乘、判断素数、打印图形），**定义只写一次，不会自动执行**

# 二、函数调用

就是在别的地方写 `函数名(实参)`，**启动这个函数去干活**。

- 有参调用：`max(3,5)`，这里 3、5 是实参，把数据传给形参 x、y
- 无参调用：`print_star()`，不传数据
- 调用时：实参 → 拷贝给形参；函数开始执行里面代码

> 注意：定义是写规则，调用才是让它跑起来

## 三、函数运行过程

1. 程序从 main 开始运行，遇到函数调用语句；
2. 暂停 main，把实参的值传给函数的形参；
3. 进入被调用函数，从上往下执行函数里面代码；
4. 如果碰到`return`：带回返回值，立刻退出这个函数；
5. 回到刚才 main 里面调用它的位置，用返回值继续往下执行 main；
6. 函数局部变量在函数运行时分配内存，函数结束后自动释放。


#### 写函数交换两个整数，并说明为什么形参要用指针。

```c
void swap(int *x, int *y) 
{ 
int t = *x; 
	*x = *y; 
	*y = t; 
}
int main(void)
{    
	int a = 3, 
	b = 5;    
		swap(&a, &b);            /* 传地址，函数内通过指针改实参 */    printf("%d %d\n", a, b); /* 输出 5 3 */    
		return 0;
}
```

解析：若写成 swap(int x, int y)，函数内交换的只是副本，实参不变。交换需要 "回写"，只能靠指针。
# 函数的嵌套调用

### 例题：函数嵌套调用（C 语言，课本经典款）

题目：求 \(s=2^2! + 3^2!\) 思路： 写 3 个函数：

1. `int square(int n)`：求平方 \(n^2\)
2. `int fact(int n)`：求阶乘 \(n!\)
3. `main`：调用 square，square 里面再调用 fact，形成**嵌套调用**

```c

#include <stdio.h>
// 求阶乘
int fact(int n)
{
    int i, res = 1;
    for(i = 1; i <= n; i++)
    {
        res = res * i;
    }
    return res;
}

// 求平方，内部调用fact（嵌套）
int square_fact(int n)
{
    int s = n * n;
    return fact(s);
}

int main(void)
{
    int sum;
    sum = square_fact(2) + square_fact(3);
    printf("sum = %d\n", sum);
    return 0;
}
```

# 函数的递归

1.解决1的时候怎么工作
2.解决n-1是怎么工作（递归的信任跳跃）
3.解决n-1怎么到n

## 汉诺塔（Hanoi）

## 题目规则

三根柱子 A、B、C；A 上有 `n` 个圆盘，大盘在下、小盘在上。 要求全部移到 C，规则：

1. 一次只能移动一个盘
2. 任何时刻大盘不能放在小盘上面
3. 可以借助 B 中转

## 递归思路

设 `hanoi(n, A, B, C)`：把 `n` 个盘子，从 A，借助 B，搬到 C。 三步：

1. 把上面 `n−1` 个盘子，从 A，借助 C，搬到 B
2. 把最底下最大那一个盘子，直接 A → C
3. 把 `n−1` 个盘子，从 B，借助 A，搬到 C

**递归出口：`n == 1`，直接把这个盘子从源柱移到目标柱。** 移动总次数公式：2<sup>n</sup>-1；64 个盘子就要 2<sup>64</sup> -1次，数量极大。


```c
#include <stdio.h>
void hanoi(int n, char A, char B, char C)
{
    if(n == 1)
    {
        printf("%c --> %c\n", A, C);
    }
    else
    {
        hanoi(n-1, A, C, B);   // 第一步：n-1个 A→B，借C
        printf("%c --> %c\n", A, C); // 第二步：最大盘 A→C
        hanoi(n-1, B, A, C);   // 第三步：n-1个 B→C，借A
    }
}
int main(void)
{
    int m;
    scanf("%d", &m);
    hanoi(m, 'A', 'B', 'C');
    return 0;
}

```
