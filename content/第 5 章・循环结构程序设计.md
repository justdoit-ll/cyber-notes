```c
#include <stdio.h>

int main(void)

{

int n, i, cnt = 0;

for (n = 101; n <= 199; n += 2) { /* 偶数直接跳过 */

for (i = 2; i * i <= n; i++)

if (n % i == 0) break;

if (i * i > n) { /* 内层正常结束说明未找到因子 */

if (++cnt % 5 == 0) printf("\n");

}

}
```
【例 5-2】输入一个整数，逆序输出它的各位数字，并求各位数字之和。
```c
int n, sum = 0;

scanf("%d", &n);

while (n > 0) {

printf("%d", n % 10);

sum += n % 10;

n /= 10; /* 每轮去掉最低位 */

}

printf("\n各位数字之和 = %d\n", sum);
```
解析：取最低位用 %10，去掉最低位用 /10，这是数字拆解的固定套路；循环条件是 n>0，天然处理了 "位数不定"。
