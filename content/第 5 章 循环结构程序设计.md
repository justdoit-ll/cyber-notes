2. （1）题目用一重循环编程计算 s=1！+2！+3！+4！+…+20!
```c
#include <stdio.h>
int main()
{
    int i;
    long long s = 0;    // s 存总和
    long long fact = 1; // fact 存每个数的阶乘
    for (i = 1; i <= 20; i++)
    {
        fact = fact * i;  // 计算 i!
        s = s + fact;     // 把 i! 加到总和
    }
    printf("s = %lld\n", s);
    return 0;
}

```

核心技巧：**不用每次重新算阶乘** \(1! = 1\) \(2! = 1! \times 2\) \(3! = 2! \times 3\) \(4! = 3! \times 4\) …… \(i! = (i-1)! \times i\)

|i|fact = fact * i（得到 i!）|s = s + fact（累加）|
|---|---|---|
|1|fact = 1 * 1 = 1 → 1!|s = 0 + 1 = 1|
|2|fact = 1 * 2 = 2 → 2!|s = 1 + 2 = 3|
|3|fact = 2 * 3 = 6 → 3!|s = 3 + 6 = 9|
|4|fact = 6 * 4 = 24 → 4!|s = 9 + 24 = 33|
|…|…|…|
|20|fact 算出 20!|s 累加完所有，得到最终和|
算阶乘时每一个阶乘等于上一个阶乘*本身
 即s = s + fact;

3.（1）题目输入两个正整数 m 和 n，求其最大公约数和最小公倍数

思路：

1. 输入 m、n，先分出`min`较小数、`max`较大数
2. **求最大公约数（gcd）**：从 min 往下挨个试，第一个能同时整除 m 和 n 的，就是最大公约数，`break`跳出
3. **求最小公倍数（lcm）**：从 max 往上挨个试，第一个能同时被 m、n 整除的，就是最小公倍数，`break`跳出
```c
#include <stdio.h>
int main()
{
    int m, n, i;
    int gcd = 1, lcm;
    int min, max;

    printf("请输入两个正整数m和n：");
    scanf("%d %d", &m, &n);

    // 找出m和n中的较小值和较大值
    if (m < n)
    {
        min = m;
        max = n;
    }
    else
    {
        min = n;
        max = m;
    }
    // 遍历求最大公约数
    for (i = min; i >= 1; i--)
    {
        if (m % i == 0 && n % i == 0)
        {
            gcd = i;
            break; // 找到了最大的，直接跳出循环
        }
    }
    // 遍历求最小公倍数
    for (i = max; ; i++)
    {
        if (i % m == 0 && i % n == 0)
        {
            lcm = i;
            break; // 找到了最小的，跳出循环
        }
    }

    printf("最大公约数gcd=%d\n", gcd);
    printf("最小公倍数lcm=%d\n", lcm);
    return 0;
}

//最大公约数的条件
//m % i == 0 && n % i == 0
//最小公倍数的条件
//i % m == 0 && i % n == 0
```
>[waring]
>在求最小公倍数是循环次数是无限的不用填值，当找到后自动跳出整个循环。

## 迭代（辗转相除法，求最大公约数 GCD）

✅ **做题方法** 辗转相除公式：

```
r = m % n
m = n
n = r
```

直到`n==0`，此时 m 就是最大公约数；最小公倍数：\(lcm = m*n / gcd\)
例题：输入两个整数，求最大公约数

```c
#include <stdio.h>
int main()
{
    int m,n,r;
    scanf("%d%d",&m,&n);
    while(n != 0)
    {
        r = m % n;
        m = n;
        n = r;
    }
    printf("gcd=%d",m);
    return 0;
}
```

解析：反复取余数，不断更新 m、n，余数为 0 停止，速度远快于暴力枚举。
```
```# ==辗转相除法（欧几里得算法）原理==

公式：

> \(\boldsymbol{gcd(m,n) = gcd(n,\ m\bmod n)}\) 直到余数为 0，此时的除数就是最大公约数。

一句话核心：**两个数的最大公约数，等于【较小数】和【两数相除余数】的最大公约数**。

---

## 通俗理解

假设 \(m>n\)，把 m 写成：

\(m = q \times n + r\) q 是商，r 是余数，\(0\le r<n\)。

如果一个数 d 能同时整除 m 和 n： \(d\mid m,\quad d\mid n\) 那么 d 一定可以整除 \(r = m - q\times n\)。 👉 也就是说：**m、n 的公因数，一定也是 n、r 的公因数**。

反过来，能同时整除 n 和 r 的数，也一定整除 m。 👉 所以：\(\boldsymbol{m,n}\) 和 \(\boldsymbol{n,r}\) 的公因数完全一样，最大公约数自然相同！

所以：

\(gcd(m,n)=gcd(n,r)\)

我们不断把新的除数、余数代入，反复缩小数字： \(gcd(m,n)\rightarrow gcd(n,r_1)\rightarrow gcd(r_1,r_2)\rightarrow\dots\) 直到余数 \(r=0\)。 当余数 = 0 时，除数就是最大公约数。

---

## 举例子：gcd (18,12)

1. \(18 = 1\times 12 + 6\)，\(r=6\) \(\Rightarrow gcd(18,12)=gcd(12,6)\)
2. \(12 = 2\times 6 + 0\)，\(r=0\) 余数是 0，除数 6 就是 gcd。

**不用提前判断谁大！** 这是辗转相除法一个很妙的点。

原理： 如果 \(m < n\)，那么 \(m \% n = m\)

## 递推（Fibonacci 斐波那契数列）

✅ **做题方法** 已知前两项，后面每一项由前面项推出来：\(f(n)=f(n-1)+f(n-2)\) 初始：\(f_1=1,\ f_2=1\)

✅ 例题：输出前 20 项斐波那契

```c
#include <stdio.h>
int main()
{
    int i;
    long long a=1,b=1,c;
    printf("%lld %lld ",a,b);
    for(i=3;i<=20;i++)
    {
        c = a + b;
        printf("%lld ",c);
        a = b;
        b = c;
    }
    return 0;
}
```

解析：a、b 保存最近两个数；c 是新数；然后滚动更新 a、b，向后递推。

### 常见需求：左下三角九九乘法表（考试最常考）

效果：

```
1*1=1   
2*1=2   2*2=4   
3*1=3   3*2=6   3*3=9
……
```

修改点：==内层 `j <= i`==，并且一行结束后换行 `printf("\n");`

```c
#include<stdio.h>
int main()
{
    int i,j;
    for(i = 1;i <= 9 ;i++)
    {
        for(j = 1;j <= i;j++)
        {
            printf("%d*%d=%-4d",i,j,i*j);
        }
        printf("\n"); // 一行打印完换行
    }
    return 0;
}
```

>[!note]
>**针对求1! + 2! + ... + 20!**

如果使用普通的 int 类型（通常是32位，最大约21亿）来存储阶乘结果，在计算到 13! 时（约62亿）就会发生数据溢出，导致最终结果为负数或错误的数值。

**解决思路**：需要使用更大范围的数据类型，如 long long（64位）甚至更高精度的数据类型。同时，循环累加时要注意不要每次重新从1乘到n（会超时），应该在上一项的基础上乘当前数，即 S = S + term; term = term * i;
